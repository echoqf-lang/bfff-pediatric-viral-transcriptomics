# Model-input boundary

Downloaded processed expression matrices and serialized expression objects are intentionally excluded from this DOI staging package. Their GEO accessions, roles, sample manifests, and available checksums are archived under `metadata/`.

Before executing the analysis scripts, obtain the processed Series Matrix data from GEO and recreate the local paths expected by the scripts. Do not substitute raw CEL, IDAT, FASTQ, or SRA processing for the processed-only workflow without documenting it as a new analysis.
