# Task 10 操作化说明：跨队列匹配随机基因集

**记录日期：** 2026-08-05（Asia/Shanghai）

**状态：** 在生成任何随机集合前冻结

**性质：** 对预注册 Task 10 未明确的跨队列随机集合身份和匹配不足处理作透明操作化；不改变主要假设、确认性队列、统计量、阈值、随机次数或决策规则。

## 背景与不变边界

原预注册要求在各队列实际可检测基因宇宙中，按平均表达五分位、检测率五分位和探针数分层，生成 10,000 个与真实主靶点集等大的随机集合，并运行相同的 `camera` 与加权 Stouffer 流程。两个确认性队列的可检测基因宇宙和真实可检测目标子集并不完全相同，因此需要在查看任何随机集合统计量前明确跨队列集合身份。

Task 8 已判定 `H1_not_supported_camera_component_failed`。Task 10 仍按原计划完成，但其结果不能补救该失败判定。本任务不运行敏感性队列、探索性队列、单基因 Meta 或其他未注册校准。

## 冻结操作规则

1. 队列分别匹配：GSE105450 与 GSE103842 在各自实际可检测、唯一当前 Entrez 映射的基因宇宙内独立构造随机集合。
2. 集合大小严格等于各队列真实可检测目标子集：GSE105450 为 391 个基因，GSE103842 为 374 个基因。
3. 同一迭代编号的两个队列随机集合配对后，按 Task 8 的固定独立受试者数权重 `sqrt(122)` 与 `sqrt(73)` 合并带方向 `camera` Z。由于可检测宇宙和真实目标子集不同，不要求两个队列抽到相同 Entrez ID。
4. 候选基因只来自该队列非目标的可检测基因；每个随机集合内无放回抽样，不得有重复基因或真实目标混入。
5. 匹配变量仅为盲态 QC 后保留样本上的：
   - 全样本平均表达五分位；
   - Detection P 可检测率五分位；
   - 该 Entrez 对应的 `unique_current` 探针数五分位。
6. 五分位切点在每个队列的全部实际可检测基因宇宙上分别确定；真实目标在 125 个三维分层中的计数逐队列固定。不得使用病例效应、P 值、病例标签或网络中心性构造匹配变量。
7. 若某精确三维分层的非目标候选不足，按以下预定顺序放宽，并记录每次分配的来源层：
   - 先仅放宽探针数档，始终保持平均表达档和检测率档相同；按探针数档与原档距离由近到远分配，同距离时按较低档后较高档的确定性顺序；
   - 仍不足时，逐步允许相邻检测率档，同时始终保持平均表达档相同；先按检测率档距离、再按探针数档距离、最后按较低档后较高档的确定性顺序分配；
   - 若保持平均表达档后仍无法满足集合大小，停止分析并报告，不继续放宽平均表达档。
8. 随机种子固定为 20260804。严格生成 10,000 次，不提前停止；允许分块保存和恢复，但恢复必须由迭代编号及输入/规则校验和验证。
9. 每个随机集合使用与真实集合完全相同的队列内 `camera` 表达矩阵、设计矩阵、病例系数、全可检测背景和方向定义。若为计算效率缓存数学等价的设计或残差量，须先以少量固定集合逐项证明与直接 `limma::camera` 数值一致；不得未经证明改用 `cameraPR` 或其他近似实现。
10. 观察统计量必须先从冻结的 Task 5/7 输入重建 Task 8 结果并与保存的两队列 `camera` P、方向、带方向 Z 及加权 Stouffer Z 完全核对。观察综合统计量固定为 Task 8 的带方向 Stouffer Z。
11. 双侧经验 P 值固定为 `(1 + sum(abs(T_random) >= abs(T_observed))) / 10001`；同时报告观察统计量在 10,000 个随机综合统计量中的百分位。

本说明在任何随机抽样和随机 `camera` 计算前单独提交，以保留时间顺序证据。
