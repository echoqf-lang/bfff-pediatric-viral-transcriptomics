# Task 10 实现前补充：五分位并列值与固定分配

**记录日期：** 2026-08-05（Asia/Shanghai）

**状态：** 在生成任何随机集合前冻结

为避免探针数等离散匹配变量在分位点出现大量并列值时被任意拆分，五分位档按每个队列实际可检测基因宇宙中的经验中秩定义：先对变量取 `rank(ties.method="average")`，再将 `ceiling(5 * rank / N)` 限制到 1–5。相同数值始终进入同一档；因此某些档允许为空，但档位标签仍为 1–5。该规则只使用盲态匹配变量。

候选不足的固定分配在抽样前由分层计数一次性确定：先逐三维分层分配 exact；随后在每个固定表达档和检测率档内按探针档距离由近到远分配；最后在固定表达档内按检测率档距离、探针档距离依次分配。相同距离按较低来源档后较高来源档排序。固定分配表保证每个来源分层的总使用数不超过其非目标候选数；每次迭代只在各来源分层内部无放回随机抽样，不依据任何 `camera` 结果改变分配。
