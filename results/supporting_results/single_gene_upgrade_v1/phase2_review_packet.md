## 2. 固定BloodGen3模块结果

- GSE38900：359/382个模块达到≥50%覆盖，122个在队列内BH<0.05。
- GSE77087：367/382个模块达到≥50%覆盖，185个在队列内BH<0.05。
- GSE103842：346/382个模块达到≥50%覆盖，144个在队列内BH<0.05。
- 三队列共同可评价模块：345个。
- 三队列中位log2FC同向：213/345个。
- 至少两个队列BH<0.05：144个；三个队列均BH<0.05：68个。
- 固定86基因中68个可映射至BloodGen3模块，18个未映射；因部分基因属于多个模块，共得到90条映射关系。

三个队列均显著且同向的代表性模式包括：

- 上调：I型干扰素／干扰素、炎症、单核细胞、中性粒细胞及中性粒细胞活化模块；
- 下调：T细胞、B细胞、淋巴细胞和部分抗原呈递模块。

这些结果支持“儿童RSV全血中存在可跨队列重复的抗病毒—髓系增强及淋巴细胞相关下降转录格局”。它们不能证明补肺防感方已作用于这些模块，也不能区分细胞比例变化与细胞内转录变化。

## 3. 细胞组成敏感性门控

- 人工两细胞混合验证：Spearman rho约0.999，算法方向检查通过。
- 真实数据状态：`stopped_by_qc`。
- 原因：未找到适用于婴幼儿急性RSV全血芯片的、固定且可公开审计的比例参考签名。成人LM22或肿瘤RNA-seq参考存在明显人群／平台失配。
- 因此未生成真实细胞比例、细胞校正后的基因效应或衰减结果；这是按预设规则停止，并非分析遗漏。

## 4. 建议写入论文的层级

1. 将三队列单基因Meta、严重程度和病毒特异性保留为主证据层。
2. 将BloodGen3结果作为次要的功能组织层，突出跨队列方向重复，不宣称中药调控机制。
3. 明确写出细胞反卷积未通过适用性门控；将髓系／淋巴细胞模块解释为可能同时包含细胞组成和细胞状态信号。
4. 不添加来源失配的LM22图来“补齐”结果，避免审稿人追问儿童参考适用性、平台尺度和伪精确比例。
